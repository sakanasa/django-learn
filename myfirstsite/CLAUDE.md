## Commands

```bash
# Run development server
python manage.py runserver

# Run all tests
python manage.py test

# Run tests for a specific app
python manage.py test apps.home_page
python manage.py test apps.pie_chart

# Apply migrations
python manage.py migrate

# Create migrations after model changes
python manage.py makemigrations

# Django shell
python manage.py shell
```

## Architecture

This is a Django 5.2 project (`myfirstsite`) with a multi-app structure. All apps live under `apps/`, and `apps/` is inserted into `sys.path` in `settings.py`, meaning apps can be imported without the `apps.` prefix in most contexts. However, `ws_damage_sim` and `ws_to_discord` are registered with full `apps.` prefix in both `INSTALLED_APPS` and `urls.py` — be consistent with whichever pattern an app already uses.

**Database**: SQLite (`db.sqlite3`). **Timezone**: Asia/Taipei.

**URL routing** (`myfirstsite/urls.py`): Root `/` redirects to `/home_page/`. Each app has its own `urls.py` included under its prefix.

**Templates**: Global templates live in `templates/` (project root). App-specific templates follow Django's `APP_DIRS` convention (`apps/<app>/templates/<app>/`). The base layout is `templates/base.html`.

**Static files**: All static assets are in `static/` (project root). The static template includes a SB Admin 2 theme (Bootstrap 4, DataTables).

### Services pattern

Apps with external I/O use a `services/` subdirectory:
- `deck_analysis/services/scraper.py` — Decklog REST API fetching, card merging, CX combo detection (concurrent via `ThreadPoolExecutor`)
- `deck_analysis/services/llm.py` — Ollama chat API calls, prompt building
- `deck_showcase/services/scraper.py` — Multi-source scraping (Decklog JP/EN, Bottleneko)
- `deck_showcase/services/showcase.py` — Deck presentation logic
- `finance_brief/services/llm.py` — Ollama market summary generation
- `finance_brief/services/market_data.py` — Market data fetching
- `finance_brief/services/news_fetcher.py` — News headline fetching
- `stock_market/services/market_data.py` — Stock data fetching

### LLM integration

LLM calls use a self-hosted **Ollama** server on a remote Mac Studio (accessible via Tailscale). Settings in `settings.py`:
```python
OLLAMA_BASE_URL = 'http://100.94.135.11:11434'
OLLAMA_MODEL = 'qwen2.5:72b-instruct-q4_K_M'
```
Services read these via `getattr(settings, 'OLLAMA_BASE_URL', ...)`. LLM responses for deck analysis and finance briefs are in **Traditional Chinese (繁體中文)**.

### Authentication

Uses Django's built-in auth views (`/login/`, `/logout/`). Template at `templates/auth/login.html`. `LOGIN_REDIRECT_URL` is `/home_page/`. Only `home_page` edit view requires login.
