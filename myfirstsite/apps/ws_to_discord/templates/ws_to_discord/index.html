WsToDiscord

自動監控日本 Weiß Schwarz 卡牌店庫存的 Discord Bot。每 30 分鐘爬取多家日本卡牌店，偵測新品上架、價格異動與售完事件，透過 Rich Embeds 即時推播至 Discord。

Running discord.py GCP Docker

核心功能

多店舖爬蟲

同時監控多家日本卡牌店，解析商品名稱、價格、庫存狀態，結構化為 dataclass 物件。

BeautifulSoup4 Requests dataclasses

變動偵測

將上次爬取結果序列化為 JSON 存入 GCS，新一輪爬取後進行差異比對，生成 ChangeEvent 列表。

JSON State GCS Diffing Logic

Discord 推播

依事件類型（新品/漲價/售完）選用不同顏色的 Embed，附上商品圖片連結即時推送至指定頻道。

discord.py Embeds image attachments

Slash Commands

支援互動式指令查詢庫存，無需等待定時推播即可隨時取得最新資料。

/stock /stockimg /update /emoji-stats

雙模式部署

持久 Bot 模式（APScheduler 內建排程）與 Cloud Run 一次性執行模式，依需求靈活切換。

Cloud Run APScheduler Docker

實作亮點

ProductSnapshot 差異邏輯

每筆商品以 @dataclass 表示，比對新舊快照時產生帶有事件類型的 ChangeEvent，確保推播訊息包含完整的前後差異資訊。

@dataclass ChangeEvent Diff Algorithm

雙儲存後端抽象

透過統一介面支援本地 JSON 檔（開發用）與 Google Cloud Storage（正式環境），切換後端只需更改設定，不影響業務邏輯。

Local JSON GCS Bucket Backend Abstraction

持久 Bot vs 一次性執行

bot.py 使用 APScheduler 維持長駐程序，同時支援 Slash Commands；main.py 以無狀態方式執行單次爬取，適合 Cloud Run Job 部署。

bot.py main.py APScheduler

GCP Secret Manager 金鑰管理

Discord Bot Token 與敏感設定均存放於 GCP Secret Manager，容器啟動時動態載入，確保金鑰不暴露於映像檔或環境變數中。
